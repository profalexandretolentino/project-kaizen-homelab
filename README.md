# English

## Overview

Project Kaizen is a long-term engineering laboratory dedicated to Software Engineering, Infrastructure, Cloud, DevOps and Continuous Learning.

The project treats each implementation as a real engineering initiative, with emphasis on reproducibility, documentation, automation and continuous improvement. Its purpose is not only to build infrastructure and services, but also to produce reusable engineering knowledge.

Project Kaizen serves as:

- an engineering laboratory;
- a technical portfolio;
- a continuous learning platform;
- a knowledge legacy.

The repository evolves incrementally through engineering Sprints. Each delivery improves the project and keeps its implementation, documentation and engineering decisions aligned.

## Quick Start

1. Read the [Manifest](MANIFEST.md) to understand the project's identity and purpose.
2. Read the [Philosophy](PHILOSOPHY.md) to understand how engineering work is approached.
3. Read the [Constitution](CONSTITUTION.md) before changing code, infrastructure or documentation.
4. Review the [Architecture](ARCHITECTURE.md) to understand the repository and its components.
5. Check the [Roadmap](ROADMAP.md) for planned phases, milestones and backlog.
6. Use the [Changelog](CHANGELOG.md) to follow completed releases and changes.

# Português

## Visão Geral

O Project Kaizen é um laboratório de engenharia de longo prazo dedicado à Engenharia de Software, Infraestrutura, Cloud, DevOps e Aprendizado Contínuo.

O projeto trata cada implementação como uma iniciativa real de engenharia, com ênfase em reprodutibilidade, documentação, automação e melhoria contínua. Seu propósito não é apenas construir infraestrutura e serviços, mas também produzir conhecimento de engenharia reutilizável.

O Project Kaizen atua como:

- laboratório de engenharia;
- portfólio técnico;
- plataforma de aprendizado contínuo;
- legado de conhecimento.

O repositório evolui de forma incremental por meio de Sprints de engenharia. Cada entrega melhora o projeto e mantém alinhados sua implementação, sua documentação e suas decisões de engenharia.
